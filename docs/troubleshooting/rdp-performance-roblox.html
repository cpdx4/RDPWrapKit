Improving RDP performance — Roblox Edition

If Roblox stutters or crawls inside your RDP, the session is spending its resources on things the game never sees. This checklist strips an RDP session down to the bare minimum — lean shortcut settings, a stripped-down session, a capped FPS, and a hands-off window.

Why Roblox lags in RDP

Every frame has to share the session with everything else it draws

Am I affected? Roblox runs inside your RDP, but it stutters, drops frames, or feels laggy.

Cause: The RDP session is busy drawing visual effects, launching startup apps, feeding Widgets, and rendering frames nobody is watching.

The fix: Work through the checklist below — performance-first shortcut settings, a bare-bones session, a capped FPS, and a minimized window.

Each step removes work the session no longer has to do. The first two are set once in the shortcut itself; the rest are applied inside the session. Do them in order, then play.

Steps 1–2: set the shortcut up for performance

Done once on RDPWrapKit's Shortcut Settings page

These settings are written into the shortcut file itself. Set them once and every future connection uses them. Already created your shortcut? Re-run Setup and choose Edit existing shortcut settings to change them.

  1. 01

    Create the RDP shortcut with the default resolution

    Create the RDP shortcut with RDPWrapKit and leave Window Size at its default, 1366 x 768. A smaller window means fewer pixels to push for every frame — the single biggest FPS lever you have.

    Keep Full Screen unchecked. Full screen renders at your monitor's native resolution, which is exactly what you don't want here.

  2. 02

    Set the shortcut's Quality vs Performance options to performance

    On the same Shortcut Settings page, click Quality vs Performance (click to expand) and uncheck all six checkboxes:

    • Desktop wallpaper
    • Smooth text (ClearType)
    • Transparent windows & effects
    • Show window contents while dragging
    • Animated menus & transitions
    • Visual themes

    Unchecked = better performance. Every box you uncheck is one less thing the session has to draw.

Steps 3–8: strip the session while it runs

Apply these inside the RDP, before you start playing

  1. 03

    Set Windows' visual appearance to "best performance" in the RDP

    Inside the RDP, open Start and search for "Adjust the appearance and performance of Windows". Open it, select Adjust for best performance, and click OK.

    The window is also reachable via Settings > System > About > Advanced system settings > Performance Settings.

  2. 04

    Turn off all startup apps in the RDP

    Inside the RDP, open Task Manager (Ctrl+Shift+Esc), go to Startup apps, right-click each app, and choose Disable.

    Restart the RDP session afterwards. The disable only takes effect after a restart, and that restart is what frees the resources.

  3. 05

    Turn off Widgets and unnecessary icons on the Taskbar

    Inside the RDP, right-click an empty spot on the taskbar and choose Taskbar settings. Turn off Widgets, then toggle off any taskbar items you don't need (Search, Task view, and similar).

    Back on the taskbar, right-click any icon you don't use and choose Unpin from taskbar.

  4. 06

    Set Roblox graphics to Manual, 1 — then close it

    In Roblox inside the RDP, open the Roblox menu (Esc), go to Settings, set Graphics Mode to Manual, and drag Graphics Quality down to 1. Then close Roblox completely so the setting saves and it starts clean next time.

  5. 07

    Set Natro Macro's FPS Editor to 20

    Open Natro Macro inside the RDP, open the FPS Editor, and set it to 20. Capping the FPS keeps the session from burning CPU on frames you can't see anyway.

  6. 08

    Minimize the RDP and don't look at it

    While the RDP is running, minimize the window and leave it alone. A minimized session skips most of the frame-drawing work, leaving the full budget to Roblox. Resist the urge to click in and watch — let it run in the background.

Step 9: clean up your main PC too

The PC you watch the RDP from matters as well

  1. 09

    Turn off startup apps on your main PC

    Repeat step 04 on your main PC: open Task Manager, go to Startup apps, and disable what you don't need. This time, keep Enabled anything you rely on when your PC starts up.

    Disabled apps aren't removed — anything you disable can still be opened manually whenever you need it.

Still lagging?

Run the built-in FPS troubleshooter

If things are still lagging after the checklist, run the RDPWrapKit installer and choose Quick Fixes, then pick Low FPS and Lag Troubleshooting and click Next. It applies RDP settings that commonly fix low frame rate and lag.

When it finishes, reconnect your RDP session for the changes to take effect.
